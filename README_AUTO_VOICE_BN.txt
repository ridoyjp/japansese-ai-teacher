Japanese Ai Ebook — Auto Voice Send

মাইকে একবার চাপুন → বাংলা বা Japanese বলুন → প্রায় ২ সেকেন্ড থামুন → Automatic transcription and chat send.
Language selection এবং manual Stop button প্রয়োজন নেই।

IMPORTANT: নতুন Worker কোড আগের /transcribe API-ই ব্যবহার করে। Worker আগেই একই সংস্করণে Deploy করা থাকলে Worker আবার Deploy লাগবে না। নইলে npx wrangler deploy --config wrangler.jsonc চালাতে হবে।

Speech detection iPhone/Android microphone permission, browser AudioContext, পরিবেশের noise, এবং Gemini audio transcription support-এর ওপর নির্ভর করে। ফোনে real-device test করা হয়নি।
